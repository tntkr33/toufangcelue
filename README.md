# 货源投放周策略转导入 Excel

这是一个本地 Web 工具，用于读取周策略表里的“本期投放策略”，按用户选择的系统导入格式批量生成真正的 Excel 97-2003 `.xls` 导入表。

## v2.0 客户投放查询

### 品规复核与另存为顺序（2026-10-09 调整）

“解析并预览校验”和“导出 XLS”之间新增“复核品规清单”。可提前逐项或批量调整品规范围，点击“确认并应用清单”一次性确认，不要求逐项勾选已复核；此操作本身不保存文件。直接点击“导出 XLS”时，尚未确认的会先弹出清单，确认成功后才打开系统另存为。取消复核或确认失败不会打开保存窗口。

当前数据已有确认清单时直接进入另存为；重新解析、切换模板或应用文字/数量修改后需重新确认。策略页与客户查询仍共享同一份品规范围，复核清单不要求上传客户表。保存窗口内更名后的日期校验仍按最终文件名执行，不改变 XLS 内容生成逻辑。

新增独立的“客户投放查询”页签，原系统导入 XLS 功能保留。

1. 先在策略页上传、解析并复核周策略，应用需要的文字或数量修改。
2. 切换到“客户投放查询”，即可搜索全部已解析品规。上传客户基本信息 `.xlsx` 后显示已导入文件名和客户数，可使用“更换客户信息表”替换。
3. 首次明确选择“单周 / 双周”和“本周是否为每月一订投放周”后自动统计。选择品规、营销部、市场类型和起止档位，结果自动更新。也可切换客户明细或未匹配清单，无需再点查询按钮。
4. 导出当前视图、当前已查询筛选条件下的全部记录，而非当前分页。统计报表为 `.xlsx`，通过系统另存为保存，成功后可打开文件或所在位置。

**统计口径：**这是按策略测算的投放量，不是实际订货量。一周一次（每周一订）正常计算；两周一次按周次“第一周”对应单周、“第二周”对应双周；每月一订仅在选择相应投放周时计算。不符合周期的客户仍保留，投放量为0，不额外注明原因。不按周几筛除。使用当前已应用的档位数量；条数汇总后按 250 条 = 1 箱换算，箱数显示三位小数。客户数是唯一客户数，不是品规与客户组合行数。

**周期异常：**按表头读取“订货周期类型”（或“订货周期”）和“周次”。周期为空、无法识别，或两周一订的周次缺失/无效时，客户仍保留在明细中，数量为0，并提示复核。未匹配清单包含客户编码、名称、周期、周次和异常原因；导出报表记录本次所选策略周及每月一订选项。其他维度缺失、客户编码冲突等原有校验保持不变。

客户表中的“四周一次”按“每月一订”处理，只看“本周是否为每月一订投放周”的选择，不再按其“周次”字段筛选。

“本周应投客户数（去重）”统计当前区县、市场类型和档位范围内，周期有效且符合本周订货条件的客户，不是全部客户数，也不是某品规非零投放客户数。非本周订货客户仍保留在明细中，数量为0；周期异常客户不计入应投人数，并保留复核提示。导出报表同时列出应投人数和筛选范围全部人数。

**客户字段：**按表头识别客户编码、客户名称、营销部、档位、市场类型(扩展)；商圈模板使用商圈类型(扩展)。城市、县城、乡镇、农村来自“市场类型(扩展)”，不是“业态(国标)”。客户编码按文本保留前导零。相同编码、测算字段相同的重复行去重并提示；冲突编码、缺失字段、未知维度或无对应数量的客户列入未匹配清单，不伪装成0条。

**品规与版本：**“不导出”的品规仍可搜索，并以“已排除投放”标注，客户投放数量按0统计；原策略与人工修改数量不变。查询优先使用策略页已确认的清单；尚未确认时使用默认建议，页面和报表均标注“品规范围待复核”。查询不弹出复核窗口，可点击“前往策略复核”修改清单；系统 XLS 导出仍要求确认并实际移除不导出的品规。应用修改、替换客户表或调整品规范围后自动更新查询，更新期间不能导出旧结果。重新解析新策略后需重新上传客户表。关闭工具后内存中的客户与查询数据不保留。

**大表导出：**明细分页显示，后台流式写入 XLSX，超过单表容量自动分表；导出过程中显示进度、暂时禁止修改参与计算的数据，并延后自动退出。目标文件只在写入成功后替换，不留下半成品。存在未匹配数据时，页面和报表均明确提示总量有缺项。

客户表、策略表、私有模板和统计结果仅在本机处理，不加入 Git。Windows 包不包含客户表；macOS 保留源代码与原生保存路径，但本次未做 Mac 真机测试。

## 启动

### v1.9 更新（2026-10-08）

- 数量表的区县筛选支持复选框多选、仅筛选此项、全选、取消全选和反选。默认全选，仅影响查看范围，不删除导出行，筛选切换也不会丢失未应用的数量修改。
- 每次导出均显示全部品规的确认清单，可按品规名称、商品编码、原策略或校验提示搜索，并筛选建议不导出、需人工复核、已选不导出的品规。批量操作只处理当前筛选结果中勾选的品规。
- 整品规停投、无库存、明确整品规按价位段投放默认不导出。局部或混合策略、存在不确定表述、已人工填写非零数量的品规默认保留并供复核。其他校验提示不会自动导致排除。
- 清单展示对应品规的原文、当前策略、建议原因和校验提示。“保留导出”使用当前解析与已应用的人工数量，不强制填0；“不导出”排除整品规所有维度行。原始模板和数量解析算法不变。
- 点击“确认并导出”后才应用本次清单；取消不生成所选文件。下次导出重新确认，重新解析或应用策略修改会使旧清单失效。

v1.9 导出改用系统“另存为”窗口，保存成功后提供“打开文件”和“打开文件所在位置”，指向用户实际选定的文件而非 outputs 备份。Windows 使用默认关联程序与资源管理器，macOS 使用默认关联程序与 Finder（macOS 分支尚需真机验证）。界面“区倒”更正为“区县”，私有模板原文件名及隐藏标识保持不变。

关闭最后一个工具网页后，后台在检测到连接关闭约 10 秒后自动退出；刷新或仍有其他工具网页打开时不会退出。正在解析、写入文件或系统保存窗口未关闭时，不会自动退出，也会阻止其他页面请求退出。退出后未导出的会话修改会丢失，已保存的文件不受影响。

v1.8 新增停投及无库存品规导出确认清单。明确整品规“停投”“库存不足，停投”“无库存”等默认不导出，每次导出前可逐项或批量改为“保留填0”，确认后生效。局部区县或市场类型停投、解析不确定、普通全零策略不自动排除；人工应用非零数量后也不自动排除。全部品规均被排除时不生成文件。原始策略和私有模板不会被修改。

页面右上角“退出工具”仍可立即退出。确认前请导出需要保留的结果；确认后关闭当前程序的后台服务，未导出的会话修改会丢失。解析、应用修改和导出期间暂时禁止退出。若同时运行了多份旧版工具，退出当前版本不会结束其他版本。

## 模板准备

真实模板是运行时私有业务文件，不进入公开 Git。源码运行时默认从项目根目录读取：

```text
private_templates\
```

原始 `.xls` 文件名必须是：

```text
档位+区倒+市场类型.xls
档位+区县.xls
档位+区县+商圈.xls
档位+市场类型.xls
```

配套 `.xlsx` 文件名必须是：

```text
档位+区倒+市场类型.xlsx
档位+区县.xlsx
档位+区县+商圈.xlsx
档位+市场类型.xlsx
```

商品内码映射文件名必须是：

```text
商品内码实例.xls
```

程序按商品编码从该文件读取商品内码。该映射优先于策略表中的商品内码；如果某个商品没有映射，程序会显示黄色警告并列出对应策略行，商品内码留空但仍允许导出。同一商品编码对应多个不同内码时会阻止导出。

公开的 `strategy_excel_tool/templates/` 只保留[模板说明](templates/README.md)。如果需要把私有模板放在其他位置，可设置环境变量 `STRATEGY_TOOL_TEMPLATE_DIR`。

Windows PowerShell：

```powershell
$env:STRATEGY_TOOL_TEMPLATE_DIR="D:\private\strategy_templates"
python strategy_excel_tool\server.py
```

macOS/Linux：

```bash
export STRATEGY_TOOL_TEMPLATE_DIR="$HOME/private/strategy_templates"
python3 strategy_excel_tool/server.py
```

相对路径会以项目根目录为基准解析。网页中的模板状态提示会显示当前实际加载目录和缺失文件。

## 使用流程

v1.6 修复中文保存路径导致下载连接中断，以及不带扩展名的周期文件名被日期小数点截断的问题。“另存为”中修改文件名后，程序按最终文件名中的 `YYYYMMW?(MM.DD-MM.DD)` 更新表内周期。

v1.7 对无法识别的周期、无效日期、起止倒置和月份不一致显示确认窗口。窗口同时列出输入文件名、问题原因和拟写入蓝色表头的默认周期，默认聚焦“返回修改”。只有点击“确认使用默认周期并导出”才允许使用默认周期；返回修改或按 Esc 不写入导出内容。包含跨年日期的十二月至一月周期可以正常识别。

1. 上传周策略表 `.xlsx`。
2. 在下拉框选择导出格式。
3. 点击“解析并预览校验”。
4. 检查校验提示、结构化规则 JSON 和导出预览。
5. 确认无误后点击“导出 Excel”。

工具不会在上传后直接导出，必须先完成预览校验。

## 品规复核与修改

- v1.4 校验提示默认展开，所有提示随页面完整显示，不使用独立限高滚动区；仍可点击标题手动收起。
- v1.3 使用宽屏工作台，版本号显示在左上角软件名称旁；后续发布按 v1.4、v1.5 递增。
- 搜索框默认空白，输入名称或编码自动显示匹配列表；点击完整品规后进入复核，不自动选中第一项。
- 默认只显示原文预览，点击“修改文字策略”展开“修改当前文字策略”编辑区。
- 解析后，在“品规复核与修改”中按商品名称或编码搜索，范围包含所有商品，不受预览前 150 行限制。
- 原始策略始终保留；可以修改当前策略文字并点击“重新解析并应用文字策略”。重新解析该商品会清除其已手工修改的数量，确认窗口中会提示。
- 可以按区县和市场类型筛选，在档位表中修改投放条数，再点击“应用数量修改”。已应用的数量会写入最终导出的 `.xls`。
- 应用文字或数量修改时，先显示确认清单，列出商品编码、完整名称，以及所有变化的营销部、业态、商圈、档位、修改前后数量。文字修改还会显示前后原文和解析警告；点击“确认并应用”才会生效，“返回修改”不改变导出数据且保留草稿。
- 数量表右上角支持最大化、退出最大化，也可按 Esc 退出；最大化中仍可筛选、编辑和确认修改。
- 图表左侧选择营销部，右侧按钮切换业态；含商圈时提供单独商圈选择，不会把不同商圈数量相加。点击档位柱可定位对应数量输入框。
- 有未应用的修改时禁止导出，请先应用或放弃修改。
- 修改只保存在本次运行会话中，不改动上传的策略文件或私有模板。关闭程序或重新上传解析后，需要重新复核和修改。

## 支持规则

- 自动读取包含 `商品编码`、`商品名称`、`本期投放策略` 的工作表。
- 自动按 `商品编码` 从私有 `商品内码实例.xls` 填写商品内码；缺失时警告并留空，一对多冲突时阻止导出。
- 策略列按 `本期投放策略` 表头动态定位，不绑定 O 列或 P 列；新增 `在途` 等中间字段不会影响解析。
- 自动识别模板中的商品字段、区县/市场类型/商圈字段，以及 `1档` 到 `30档` 列。
- 档位列可以倒序，例如 `30档` 到 `1档`。
- 最终文件是旧版 `.xls`，不会用修改扩展名的方式伪装格式。
- 四种导出格式分别绑定原模板隐藏首行中的系统类型标识，导出前后都会校验该行仍处于隐藏状态且标识正确。
- 导出文件第二行的投放周期会与文件名中的 `YYYYMMW?(MM.DD-MM.DD)` 同步。
- `1-30档3条` 表示 1档 到 30档每个档位都填 `3`。
- 支持多个县区并列，例如 `F县、G县：1-30档1条。`
- 支持多个类型并列，例如 `城市、县城：20-25档2条，26-30档3条。`
- 没有县区/市场类型限定的策略会套用模板中的全部维度行。
- `无库存`、空白或未识别到档位规则的商品会保留输出，所有档位填 `0`，并在校验里提示。
- `无库存`、`库存不足`、`停投`、`暂停投放` 等明确 0 投放文本会自动按 0 处理，不再作为异常刷屏。
- 导出时会先把 Excel 保存到 `outputs` 文件夹，再在页面显示保存路径；即使浏览器下载被拦截，也可以直接去该文件夹取文件。

## 打包成 exe

打包需要开发依赖。先安装：

```powershell
python -m pip install -r strategy_excel_tool\requirements-dev.txt
```

然后在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File strategy_excel_tool\build_desktop.ps1
```

打包产物会生成到：

```text
dist\卷烟投放策略转excel工具
```

打包脚本会同时生成 `卷烟投放策略转excel工具` 文件夹和 `卷烟投放策略转excel工具.zip`。把整个文件夹复制到其他电脑，或解压 ZIP 后使用；双击里面的 `卷烟投放策略转excel工具.exe` 启动。私有模板放在同级 `private_templates` 文件夹，导出文件会保存在同级 `outputs` 文件夹。

## 在另一台电脑恢复开发环境

1. 克隆公开 Git 仓库。
2. 安装 Python 3。
3. 运行 `python -m pip install -r strategy_excel_tool/requirements.txt`。
4. 在项目根目录创建 `private_templates/`。
5. 通过单位内部渠道把八个真实模板和 `商品内码实例.xls` 复制到该目录。
6. 运行 `python strategy_excel_tool/server.py`。

Windows 和 macOS 使用相同的源码、目录结构和环境变量。Windows 桌面版使用 `build_desktop.ps1` 打包；macOS 开发时可直接运行源码，后续可单独增加 macOS 打包脚本。
